# КОТТ — релизы

Публичное хранилище файлов обновления приложения «КОТТ» (Книга Описи Творческих Товаров).

Исходный код приложения — в приватном репозитории `DDmsngr/KOTT`. Здесь лежат только:

- `manifest.json` — манифест последней версии (версия, ссылка на APK), который читает приложение при проверке обновлений;
- сами APK-файлы — как ассеты GitHub Releases.

Обновляется автоматически из CI приватного репозитория при каждом релизе. Вручную не редактировать.
